# security policy

## scope

this is a static site with no backend, no forms, no accounts and no wallet connection. the only data stored is the arcade best score, in your own browser's localstorage.

the site will never ask for a seed phrase, a private key or a wallet signature. if something claiming to be this project does, it is not.

## supported versions

only the latest version on the `main` branch is maintained.

## reporting a vulnerability

please do not open a public issue.

report privately through the security and quality tab of this repository (report a vulnerability). things worth reporting: a wrong or tampered contract address, malicious scripts or links, or anything that could put a visitor's funds at risk.

i will reply as soon as i can. if the report is valid, i will fix it and update the site.
